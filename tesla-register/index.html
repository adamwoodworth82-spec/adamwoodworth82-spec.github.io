Valkyrie Jarvis — Register with Tesla

This page does one job: it registers your Tesla developer app ("Valkyrie Jarvis") with Tesla's Fleet API for North America, the step Tesla calls partner registration.

How it works, in plain terms:

  1. You paste your app's Client Secret below. It stays in this page on your phone.
  2. When you tap the button, this page sends the secret only to Tesla's sign-in address (fleet-auth.prd.vn.cloud.tesla.com) to get a short-lived partner token.
  3. The page then uses that token for one register call to Tesla (fleet-api.prd.na.vn.cloud.tesla.com) for the domain adamwoodworth82-spec.github.io, and checks the registration by reading your public key back.

Nothing is saved: no cookies, no storage, nothing is sent anywhere except the two Tesla addresses above. The secret box is cleared as soon as the call starts, and the token is never shown or stored. You can read this page's source to check — it is one file, with no outside scripts.
