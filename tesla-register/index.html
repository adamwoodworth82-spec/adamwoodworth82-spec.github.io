Valkyrie Jarvis — Register with Tesla

This page does the first half of registering your Tesla developer app ("Valkyrie Jarvis") with Tesla's Fleet API: it gets a short-lived partner token from Tesla. Jarvis then uses that token to run the register call, because Tesla does not allow browser pages to call its API directly (we tested that — the API call from a browser is blocked on Tesla's side).

How it works, in plain terms:

  1. You paste your app's Client Secret below. It stays in this page on your phone.
  2. When you tap the button, this page sends the secret only to Tesla's sign-in address (fleet-auth.prd.vn.cloud.tesla.com) to get the partner token.
  3. The page then shows you the token with a Copy button. You paste that token into the secure entry Jarvis sent you in chat — never into chat itself — and Jarvis runs the register call right away.

About the token: it is not your secret. It expires within hours and cannot be used to make new tokens. Still, treat it like a password while it is alive: do not screenshot it, do not send it in chat, only paste it into Jarvis's secure entry. Nothing on this page is saved: no cookies, no storage, and the only outside address this page talks to is Tesla's sign-in address above. The secret box is cleared as soon as the call starts. You can read this page's source to check — it is one file, with no outside scripts.
